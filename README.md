# The CosmOS Media

Public media archive for **The CosmOS** website and related experiences, including musical scores, albums and other creative assets.

## Music production

The CosmOS develops music as part of its worldbuilding: every album is grounded in its culture, environment, people and narrative role. We plan regional musical identities and album arcs before drafting individual tracks, then evaluate real recordings against their intended experience.

**Start here:** [Music Production Bible](docs/music/PRODUCTION_BIBLE.md) — creative principles, lore grounding, album/track brief standards, Suno prompt limits, iterative review, state definitions and decision tracking.

**First album plan:** [Avaloria — Volume I: Kingshelm City](docs/music/albums/AVALORIA_KINGSHELM.md) — nine planned location cues beginning with the harbor and ending with departure into the wilds.

### Standard workflow

`Research lore → Define cultural/album identity → Plan musical roles → Brief each track → Compose and generate → Listen and iterate → Approve → Implement`

Significant decisions and recurring motifs belong in the album/production documentation so they carry across tracks and future records. A drafted prompt is not an approved recording; a recording is not implemented until verified in its destination.

## Repository purpose

This repository remains a media archive, not just a prompt library. Documentation is kept alongside the media it governs and may evolve as assets, releases and integrations are added.
